# 단위 테스트 프로젝트 신설 (DCA 배분·템플릿 선택 검증)

## 개요
> DCA 매수 계산(`PlanPurchases`)과 월별 템플릿 선택 로직에 대한 xUnit 단위 테스트 프로젝트를 신설하고, 검증 가능하도록 템플릿 선택 로직을 순수 함수로 추출한다. 빌드·테스트(12건) 통과 후 main에 커밋·push 완료.

## 배경 / 목적
CLAUDE.md·recommended_rules.md는 `PlanPurchases`(순수 함수) 단위 검증을 규칙으로 요구하나, 프로젝트에 테스트 프로젝트가 전무했다. 실계좌 전환 직전이라 "무엇을 몇 주 살지" 계산이 틀리면 실제 돈이 잘못 나가므로, 매수 계산·월별 템플릿 선택 로직에 자동 안전망을 만든다.

## 본문
### 진행 계획
1. `DcaSettings.Load`의 월→템플릿 선택 로직을 동작 불변으로 순수 함수 `SelectTemplate`로 추출.
2. xUnit 테스트 프로젝트(`Tests/AutoInvest.Tests.csproj`) 신설 + 솔루션 등록.
3. `PlanPurchases`·`SelectTemplate` 규칙 시나리오 검증.
4. `dotnet test`로 통과 확인.

### 순수 함수 추출
`Core/DcaSettings.cs`에 `SelectTemplate(templates, monthMap, month)` 순수 함수를 추출했다. `Load()`는 이를 호출만 하도록 변경(외부 동작·결과 불변). 시간(KstNow)·DB(AppConfigManager) 의존을 함수 밖으로 밀어내 월 선택 규칙을 시간에 무관하게 검증 가능하게 했다.

### 테스트 프로젝트 구성
`Tests/AutoInvest.Tests.csproj`(net8.0, xUnit)를 신설하고 `dotnet sln add`로 솔루션에 등록했다.

작성한 테스트는 2종이다.

#### DcaAccumulationEngineTests (7건)
- 지정 수량 그대로 매수
- 현재가 없음·0 이하 종목 제외
- 수량 0 이하 종목 제외
- 총 매수금액 정확 합산
- 제외 종목은 총액에 미포함
- 매수 대상 없으면 빈 계획·0원

#### DcaSettingsTests (5건)
- 배정된 달에 해당 템플릿 선택
- 월 배정이 비면 첫 템플릿 사용
- 배정 없는 달 스킵
- 존재하지 않는 Id 배정 시 스킵
- 템플릿 없으면 스킵

### 빌드 함정과 해결
메인 `AutoInvest.csproj`가 루트의 Web SDK라 하위 `Tests\*.cs`를 자동 컴파일 대상에 포함해 빌드가 실패했다. `AutoInvest.csproj`에 `Compile/Content/None Remove="Tests\**"`를 추가해 해결했다.

결과: `dotnet test` → 통과 12 / 실패 0 / 기간 50ms. 메인 프로젝트 정상 빌드.

### 후속 과제
- 커밋 분리 권장안(작업 시점 기준): (1) refactor: SelectTemplate 추출, (2) test: 테스트 프로젝트 신설, (3) build: 메인 csproj Tests 제외.
- (선택) `AccumulateAsync`는 브로커 I/O 의존이라 이번 범위에서 제외했다 — 향후 IBrokerClient 페이크로 주문/기록 흐름까지 확장 가능.
- CI에서 `dotnet test` 자동 실행(GitHub Actions) 추가 여지.

## 정리 / 결론
- `SelectTemplate`를 순수 함수로 추출해 월별 템플릿 선택 규칙을 시간·DB 무관하게 검증 가능하게 만들었다.
- xUnit 테스트 프로젝트를 신설하고 배분·템플릿 선택 규칙 시나리오 12건을 통과시켰다.
- 메인 Web SDK 프로젝트가 `Tests\**`를 컴파일 대상에서 제외하도록 조정해 빌드 충돌을 해소했다.
- 상태: 완료 — 빌드·테스트 통과, main 커밋·push 완료.
