# 적립설정 예수금 대비 표시

## 개요
> 적립 설정 화면에서 기준 금액을 "예산"만이 아니라 예수금 기준으로도 보이도록, 예수금 대비 소진율 표시를 추가한다(예수금 0이면 예산 기준으로 폴백).

## 배경 / 목적
적립 설정 화면에서 기준 금액을 "예산 100만원"만이 아니라 **예수금 기준**으로도 보이도록 요청받았다.

백엔드는 이미 `/api/portfolio/summary`가 `cashBalance`(USD)와 `exchangeRate`를 반환하므로 프론트만 수정하면 된다. 사용자 결정은 두 가지였다.

- ① 예산은 유지하고 **예수금 대비 표시를 추가**한다.
- ② 예수금이 0(모의투자)이면 **예산 기준으로 폴백**한다.

## 본문
### 프론트 변경 (DcaConfig.jsx)
`DcaConfig.jsx`만 수정했다(프론트 단독).

- `cashUsd` 상태를 추가하고, 마운트 시 `/api/portfolio/summary`를 **비차단**으로 조회한다(`loadCash`). 실패하거나 0이면 예산 폴백이라 화면을 막지 않는다.
- 요약 박스에 "예수금 대비: 예수금 ₩X · 소진율 Y%" 줄을 추가하고, 초과 시 경고를 표시한다. 기존 "예산 대비" 줄과 초과 경고는 그대로 유지한다.
- 예수금 미조회(`cashUsd<=0` 또는 환율 0)면 예수금 줄 대신 "예수금 미조회 — 예산 기준으로 표시 중" 안내를 보여준다.

### KIS 모의투자 예수금 함정 (기록용)
KIS 모의투자 계좌는 해외주식 예수금 조회를 미지원해 예수금이 항상 $0이다(`KisBrokerClient.cs:214~219`). 그래서 지금 모의투자 모드에서는 예수금 줄이 뜨지 않고 예산 폴백 안내가 보이는 것이 정상이다. 예수금 기준 표시는 **실거래 전환 후** 실제 값으로 동작한다.

### 빌드
`dotnet`과 무관하며(프론트만), `npm run build`가 성공했다(오류 0).

## 정리 / 결론
사용자 테스트 항목은 다음과 같다.

- ① SimBroker 모드(`IS_PAPER_TRADING=1`, 예수금 $10,000 고정)에서 예수금 대비 줄이 정상 표기되는지 확인.
- ② 실 KIS 모의투자에서 "예수금 미조회" 폴백 안내가 뜨는지 확인.
