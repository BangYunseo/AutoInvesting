- 상태: 구현 완료 (feature/tax-guard 브랜치, 미머지 — 사용자 테스트 대기)

## 목적 / 요청

매도 시 과세 구간이면 예상 세금·수수료를 알려주고, 과세 매도는 확인(Alert) 없이는
실행되지 않게 서버에서 차단. (판단/타이밍 아님 — 세금 산수 기반 정보/가드)
설계: `Documents/260702_절세보조기능-설계계획서.md`, 근거: `Documents/analysis/260702_해외ETF-절세-가이드.md`

## 진행 / 결정

- MVP 범위: 프리뷰 + 경고 + 서버 강제 차단. YTD 실현차익은 **수동 입력**(DB 스키마 변경은 2차로 연기).
- 계산은 순수 함수 `TaxEstimator.Estimate`로 분리(단위 검증), 설정 로딩만 `TaxSettings.Load`가 담당.
- 취득가는 브로커 `HoldingDto.AvgPrice` 사용. 취득가 불명(0 이하)이면 가드 건너뜀(오차단 방지).
- 과세 매도인데 `acknowledgeTax=false`면 `OrderController.manual`이 **409 + taxEstimate** 반환.
