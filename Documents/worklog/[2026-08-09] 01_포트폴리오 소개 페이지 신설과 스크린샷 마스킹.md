# 포트폴리오 소개 페이지 신설과 스크린샷 마스킹

## 개요
> 저장소를 public으로 전환하기 위한 준비 작업. 프로젝트 소개용 단일 HTML 페이지를 `docs/`에 두어 GitHub Pages로 서빙하고, 페이지에 인라인된 실행 화면 스크린샷에서 운영 URL과 실계좌 금액을 제거했다.

## 배경 / 목적

포트폴리오 용도로 저장소를 public으로 전환하려는 상황에서, 소개 페이지를 어디에 둘지와 스크린샷에 담긴 정보가 문제가 됐다.

- 소개 페이지 초안은 claude.ai 아티팩트로 만들어 두었으나, 조직 계정이라 외부(리크루터 등)에게 링크 공유가 되지 않을 수 있다. 저장소가 어차피 public이 되므로 GitHub Pages로 옮기는 편이 확실하다.
- 페이지에 인라인된 스크린샷 5장 전부에 브라우저 주소창이 찍혀 **운영 서비스 도메인**이 노출돼 있었다. 실자금으로 주문을 내는 서비스의 로그인 주소가 포트폴리오에 박힌 채 공개되면 무차별 로그인 시도의 표적이 된다.
- 대시보드·적립 설정·거래 내역·모바일 화면에 **실계좌 재무 정보**(총자산, 예수금, 월 예산, 보유 종목별 수량·평가금액, 체결 이력의 수량과 주문번호)가 그대로 보였다.

## 본문

### 폴더 위치: `Portfolio/` → `docs/`

GitHub Pages는 배포 소스 폴더로 **브랜치 루트(`/`) 또는 `/docs` 두 가지만** 고를 수 있다. 임의 폴더명을 쓰려면 배포용 Actions 워크플로를 따로 만들어야 하므로, 폴더 이름만 바꾸는 쪽을 택했다.

프로젝트 문서 홈인 `Documents/`와는 이름이 겹치지 않는다 — `docs/`는 공개용 소개 페이지 전용이다.

### 스크린샷 처리 방식

두 가지 선택지가 있었다.

1. 금액을 이미지에서 가린다.
2. `IS_PAPER_TRADING`으로 모의 모드를 띄워 더미 데이터로 재촬영한다.

2번이 결과물은 더 깔끔하지만 앱 기동과 재촬영이 필요해 1번으로 진행했다. 히어로 이미지(대시보드)의 금액이 뭉개져 보이는 것은 감수한 부분이며, 나중에 모의 모드로 재촬영하면 그 한 장만 교체하면 된다.

처리 내용:

- **크롭** — 브라우저 탭바·주소창(상단)과 작업표시줄(하단)을 잘라냈다. 운영 도메인은 이 영역에만 있었으므로 크롭만으로 사라진다. 모바일 화면은 상태바(통신사·시각)와 내비게이션 바를 잘랐다.
- **픽셀 마스킹** — 금액·수량 영역을 블록 단위로 다운스케일 후 확대해 복원 불가능하게 만들었다. 마스킹한 곳은 대시보드 6곳(총자산, 주식 평가금액, 손익 금액, 예수금, 보유 종목 수량 열, 평가금액 열), 적립 설정 9곳(템플릿 요약 예산 2곳, 월 예산 입력값, 종목별 수량 2곳, 종목별 매수금액 라인 2곳, 총 매수금액/예산, 예수금 대비), 거래 내역 2곳(수량 열, 주문번호 열), 모바일 4곳(총자산, 주식 평가금액, 손익 금액, 예수금)이다.
- **남긴 것** — 환율, 종목 티커, 매입가·현재가, 수익률(%), 예산 대비 비중(%). 시장 공개 정보이거나, 다른 값이 가려져 있어 금액을 역산할 수 없다.
- **로그인 화면 추가** — 갤러리 첫 항목으로 넣었다. 입력란은 자리표시자 상태라 가릴 값이 없고, 카드 주변 여백이 넓어 카드 중심으로 다시 잘랐다.

원본 스크린샷은 저장소 밖(세션 임시 폴더)에만 백업했다. **원본은 저장소에 넣지 않는다** — 넣으면 마스킹이 무의미해진다.

### 마스킹 스크립트

일회성 작업이라 저장소에는 넣지 않고 세션 임시 폴더에서 실행했다. `System.Drawing`으로 크롭과 픽셀화를 수행한다. 재실행이 필요하면 아래 함수가 핵심이다.

```powershell
function Pixelate($bmp, $x, $y, $w, $h, $block) {
    $sw = [Math]::Max(1, [int]($w / $block))
    $sh = [Math]::Max(1, [int]($h / $block))
    $small = New-Object System.Drawing.Bitmap $sw, $sh
    $gs = [System.Drawing.Graphics]::FromImage($small)
    $gs.InterpolationMode = [System.Drawing.Drawing2D.InterpolationMode]::HighQualityBicubic
    $gs.DrawImage($bmp,
        (New-Object System.Drawing.Rectangle 0, 0, $sw, $sh),
        (New-Object System.Drawing.Rectangle $x, $y, $w, $h),
        [System.Drawing.GraphicsUnit]::Pixel)
    $gs.Dispose()

    $g = [System.Drawing.Graphics]::FromImage($bmp)
    $g.InterpolationMode = [System.Drawing.Drawing2D.InterpolationMode]::NearestNeighbor
    $g.PixelOffsetMode   = [System.Drawing.Drawing2D.PixelOffsetMode]::Half
    $g.DrawImage($small, (New-Object System.Drawing.Rectangle $x, $y, $w, $h))
    $g.Dispose()
    $small.Dispose()
}
```

주의점 하나 — Windows PowerShell 5.1은 UTF-8로 저장된 `.ps1`의 한글 주석을 ANSI로 읽어 파싱을 깨뜨린다. 스크립트 주석은 ASCII로 쓰거나 BOM을 붙여 저장해야 한다.

### 이미지 인라인 방식 유지

`docs/index.html`은 스크린샷을 base64 data URI로 인라인한 단일 파일(약 898KB)이다. 아티팩트로 발행할 때 외부 리소스를 못 쓰는 제약 때문에 그렇게 시작했는데, Pages에서도 그대로 동작하고 경로 문제가 없어 유지했다. 이미지를 바꿀 때는 파일만 교체하지 말고 HTML 안의 base64도 다시 만들어야 한다.

### README 정리

`## 개요`와 `## 📌 프로젝트 개요`가 같은 내용을 두 번 말하고 있어 하나로 합치고, 소개 페이지 링크를 그 자리에 넣었다. 프로젝트 구조 트리에도 `docs/` 항목을 추가했다.

## 정리 / 결론

- `Portfolio/` → `docs/`로 옮기고 GitHub Pages 배포 대상으로 삼았다.
- 스크린샷 6장에서 운영 도메인과 실계좌 금액을 제거했다. 원본은 저장소에 없다.
- 로그인 화면을 갤러리에 추가했다.
- README 개요 중복을 정리하고 소개 페이지 링크를 넣었다.

남은 일:

1. **저장소 public 전환 판단** — 워킹트리·git 히스토리·문서·프론트·인프라를 대상으로 한 노출 감사를 별도로 진행 중이다. 히스토리에 과거 시크릿이 남아 있으면 파일 삭제만으로는 해결되지 않고 로테이션과 히스토리 재작성이 필요하다.
2. **Pages 활성화** — 저장소 설정에서 `main` 브랜치 `/docs`를 배포 소스로 지정한다. 저장소가 private인 동안에는 링크가 열리지 않는다.
3. **히어로 이미지 재촬영(선택)** — 모의 모드 더미 데이터로 대시보드를 다시 찍으면 마스킹 없는 화면으로 교체할 수 있다.
