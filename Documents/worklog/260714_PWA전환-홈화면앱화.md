# 260714 PWA 전환 — 웹을 폰 홈 화면 앱처럼 실행

- 상태: 진행중
- 작성/갱신: 260714

## 목적 / 요청
"매번 브라우저 열고 주소 쳐서 들어가는 게 귀찮다. 폰 홈 화면 아이콘 탭하면 바로 뜨는 앱처럼 만들고 싶다."
→ 네이티브 앱 신규 개발이 아니라, 기존 React(Vite) SPA를 **PWA로 감싸** 코드 재작성 없이 "탭하면 뜨는" 경험을 확보.

## 계획
1. `Frontend/`에 `vite-plugin-pwa` + `@vite-pwa/assets-generator` 설치
2. `vite.config.js`에 PWA 설정 (전체화면 standalone / 다크 테마색 / API는 캐시 안 함)
3. 기존 `favicon.svg`로 iOS·안드로이드·마스커블 아이콘 자동 생성
4. 로컬 빌드 검증 → 데스크톱 설치 검증 → (승인 후) Render 배포 → 폰 검증

## 진행 / 결정
- 설치 완료: `vite-plugin-pwa`, `@vite-pwa/assets-generator`(sharp 동작 확인).
- `vite.config.js` 작성: `registerType: autoUpdate`(새 배포 시 SW 자동 갱신 → 옛 화면 캐시 방지),
  `pwaAssets`로 아이콘 자동 생성/head 주입, manifest(name "ETF 자동적립", standalone, theme `#0b0e14`).
- **API 캐싱 안 함**: workbox `navigateFallbackDenylist: [/^\/api/]` — 잔고·거래내역 등 금융 데이터가
  캐시로 굳어 옛 값이 보이는 것을 방지(항상 네트워크). 정적 자산(js/css/아이콘)만 프리캐시.
- `preview`에도 `/api` 프록시 추가(로컬에서 빌드본+API 함께 검증용).
- `npm run build` 성공: `sw.js`/`manifest.webmanifest`/아이콘(64/192/512/maskable/apple-touch-180) 생성 확인.
- **배포 정합성 확인됨**: Dockerfile이 `COPY --from=frontend-build /frontend/dist ./wwwroot`로
  dist 전체를 복사 → 새 PWA 파일 자동 포함. `Program.cs`는 `UseStaticFiles`+`MapFallbackToFile`로
  같은 오리진 서빙(PWA 전제 충족). **백엔드/Dockerfile 수정 불필요.**
- **index.html 함께 교정**: title `ETF Auto Investing`, description `해외 ETF 자동 투자`로 변경.
  기존 description의 "퀀트 지표 기반 감정 배제 매매 시스템" 문구는 Phase 6(판단 레이어 제거)에서
  틀린 문구가 된 드리프트라 PWA 브랜딩 통일과 함께 교정(PWA 커밋에 포함 예정).
- **로컬 preview 검증 완료(HTTP 레벨, 260720)**: `npm run build`(sw.js/manifest/아이콘 생성) →
  `npm run preview` → 엔드포인트 응답 확인.
  - `/manifest.webmanifest` → **200 / `application/manifest+json`**(MIME 정확), `/sw.js`·`/registerSW.js` → 200,
    `/pwa-192x192.png`·`/apple-touch-icon-180x180.png` → 200.
  - index.html에 manifest 링크·`theme-color #0b0e14`·apple-touch-icon·registerSW 스크립트 자동 주입 확인.
  - manifest 내용: name `ETF 자동적립`, `standalone`, theme/background `#0b0e14`, 아이콘 64/192/512/maskable 정상.

### 인증 구조 확인 (보안)
- 사람(폰/브라우저): 로그인 → Bearer 세션 토큰(localStorage) → `main.jsx` 인터셉터가 자동 첨부.
- 크론/머신: `x-api-key`(Render 환경변수). **프론트 번들에 시크릿이 박히지 않음** → PWA 배포해도 안전.
