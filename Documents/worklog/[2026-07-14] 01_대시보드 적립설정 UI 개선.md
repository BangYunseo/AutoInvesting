# 대시보드·적립설정 UI 개선 배치

## 개요
> 프론트 UI 다듬기 요청 4건(드롭다운 고급화, 브랜드 문구 변경, 새로고침 버튼 통합, 자산 카드 통화 전환)을 백엔드 무변경으로 처리한 배치 작업이다. 사용자 테스트 OK로 완료됐다.

## 배경 / 목적
프론트 UI 다듬기 요청 4건.

1. 드롭다운(select) 고급화 — 주문 유형·종목 선택·월별 템플릿·거래내역 개수.
2. 좌측 상단 브랜드 "AI AutoInvesting" → "ETF 적립 매수".
3. 대시보드 요약/종목 두 새로고침 버튼을 하나로 통합.
4. 대시보드 자산 카드 USD↔KRW 통화 전환.

작업 범위는 프론트 단독이며 백엔드는 무변경이다. summary 응답에 이미 있는 exchangeRate로 통화 환산을 처리한다.

## 본문
### 드롭다운 고급화 (요청 1)
`index.css`에 `select` 전용 규칙 추가 — 네이티브 화살표 제거(appearance:none) + 커스텀 SVG 셰브런(data URI) + hover/focus 색 + 옵션 다크 배경. 클래스 무관 전 select 일괄 적용.

### 브랜드 문구 변경 (요청 2)
`App.jsx` 브랜드 아이콘 "AI"→"📈", 텍스트 "AutoInvesting"→"ETF 적립 매수". "AI" 배지는 Phase 6에서 제거된 판단 레이어 잔재라 함께 정리.

참고: 로그인 화면 문구("AutoInvesting 로그인", `Login.jsx`)는 이번 범위 밖 — 필요 시 후속.

### 새로고침 버튼 통합 (요청 3)
상단 카드(총자산·주식평가금액)는 하단 보유종목(`summary.holdings`)의 합계라 데이터가 하나다. 두 버튼이 같이 돌던 건 이 구조 + 최근 perf 커밋(왕복 1회 통합) 때문. 사용자 결정으로 하단 중복 버튼 제거, 상단 "새로고침" 하나로 통일(마지막 업데이트 시각은 유지).

### 통화 토글 (요청 4)
`자산 요약` 헤더에 `$ USD / ₩ KRW` 세그먼트 토글(`.ccy-toggle`) 추가. `currency` 상태 + `fmtMoney/fmtMoneyAlt`(내부 USD 계산, 표시만 환율 환산)로 총자산·주식평가금액·예수금 3개 카드 즉시 전환. 손익금액도 같은 통화.

### 빌드 결과
`npm run build` 성공(오류 0). 미사용 변수(`totalAssetsKrw`) 정리.
