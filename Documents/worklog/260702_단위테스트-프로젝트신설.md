## 목적 / 요청
CLAUDE.md·recommended_rules.md는 `PlanPurchases`(순수 함수) 단위 검증을 규칙으로 요구하나,
프로젝트에 테스트 프로젝트가 전무했다. 실계좌 전환 직전이라 "무엇을 몇 주 살지" 계산이
틀리면 실제 돈이 잘못 나가므로, 매수 계산·월별 템플릿 선택 로직에 자동 안전망을 만든다.

2. xUnit 테스트 프로젝트(`Tests/AutoInvest.Tests.csproj`) 신설 + 솔루션 등록.
3. `PlanPurchases`·`SelectTemplate` 규칙 시나리오 검증.
4. `dotnet test`로 통과 확인.
