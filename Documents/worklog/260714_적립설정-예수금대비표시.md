# 260714 적립 설정 화면에 예수금 대비 표시 추가

- 상태: 완료(사용자 테스트 대기)
- 작성/갱신: 260714

## 목적 / 요청
적립 설정 화면에서 기준 금액을 "예산 100만원"만이 아니라 **예수금 기준**으로도 보이도록 요청받음.

## 계획
- 백엔드는 이미 `/api/portfolio/summary`가 `cashBalance`(USD)+`exchangeRate`를 반환하므로 프론트만 수정.
- 사용자 결정: ① 예산은 유지하고 **예수금 대비 표시를 추가** ② 예수금이 0(모의투자)이면 **예산 기준으로 폴백**.

## 진행 / 결정
- `DcaConfig.jsx`만 수정(프론트 단독).
  - `cashUsd` 상태 추가, 마운트 시 `/api/portfolio/summary`를 **비차단**으로 조회(`loadCash`). 실패/0이면 예산 폴백이라 화면을 막지 않음.
  - 요약 박스에 "예수금 대비: 예수금 ₩X · 소진율 Y%" 줄 추가, 초과 시 경고. 기존 "예산 대비" 줄·초과 경고는 그대로 유지.
  - 예수금 미조회(`cashUsd<=0` 또는 환율 0)면 예수금 줄 대신 "예수금 미조회 — 예산 기준으로 표시 중" 안내.
- **함정(기록용)**: KIS 모의투자 계좌는 해외주식 예수금 조회를 미지원해 예수금이 항상 $0(`KisBrokerClient.cs:214~219`). 그래서 지금 모의투자 모드에서는 예수금 줄이 뜨지 않고 예산 폴백 안내가 보이는 게 정상. 예수금 기준 표시는 **실거래 전환 후** 실제 값으로 동작함.
- `dotnet` 무관(프론트만). `npm run build` 성공(오류 0).

## 남은 일 / 다음 단계
