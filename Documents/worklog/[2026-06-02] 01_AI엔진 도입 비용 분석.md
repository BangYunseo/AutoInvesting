# Phase 4 실물 AI 시장분석 엔진 도입을 위한 비용 및 타당성 분석

## 개요
> Phase 4에서 Mock AI(`AiMarketAnalyzer.cs`)를 실제 대규모 언어 모델(LLM) API로 교체할 때 고려해야 하는 토큰 사용량, API 비용, 무료 버전 사용 가능 여부를 세부적으로 분석한 타당성 보고서다.

## 배경 / 목적
리드 에이전트(AutoInvesting 오케스트레이터)가 작성한 문서로, 향후 Mock AI(`AiMarketAnalyzer.cs`)를 실제 대규모 언어 모델(LLM) API로 교체할 때 고려해야 하는 토큰 사용량, API 비용, 그리고 무료 버전 사용 가능 여부에 대한 세부적인 분석 보고서다.

## 본문

### 토큰 사용량 추정
AI 엔진이 종목의 차트 흐름을 파악하고 정확한 판단을 내리려면 다음의 데이터가 프롬프트(입력)로 전달되어야 한다.

#### 입력 데이터 (Input Context)
- **종목 기본 정보**: Ticker (예: AAPL)
- **최근 N일의 가격 데이터**: OHLCV(시가, 고가, 저가, 종가, 거래량) 통상 20~60일치 데이터. (약 500~1,500 토큰)
- **퀀트 보조 지표**: 현재 RSI, MACD, Bollinger Bands 수치 및 Position (약 100 토큰)
- **시스템 프롬프트 (가이드라인)**: AI의 역할을 정의하고 JSON 포맷으로 응답하도록 강제하는 프롬프트 (약 300 토큰)
- *(선택)* **뉴스/매크로 지표**: 당일 증시 요약이나 헤드라인 뉴스 요약 (약 500~1,000 토큰)
- **예상되는 총 입력 토큰**: 종목당 약 **1,000 ~ 3,000 토큰**

#### 출력 데이터 (Output Context)
- `SmartOrderSignal` (BUY/SELL/HOLD)
- `ConfidenceScore` (0.00 ~ 1.00)
- `Reason` (판단 근거 약 3~4문장)
- **예상되는 총 출력 토큰**: 종목당 약 **100 ~ 200 토큰**

#### 일일 트래픽 산정
- `TradingBackgroundService`는 하루 1회 예약된 시각(예: 22:30)에 동작한다.
- 만약 포트폴리오(전략) 내에 종목이 10개가 있다면, 하루 총 10회의 API 호출이 발생한다.
- 하루 소모량: **입력 약 20,000 토큰 / 출력 약 2,000 토큰**

### 상용 모델별 API 비용 분석 (유료 사용 시)
하루 10종목, 한 달(20영업일 기준) 약 200회 호출 시 예상 비용이다.

| 공급자 | 권장 모델 | 입력 1M당 요금 | 출력 1M당 요금 | 월 예상 비용 (USD) |
|--------|---------|----------------|----------------|--------------------|
| **OpenAI** | GPT-4o-mini | $0.15 | $0.60 | **$0.10 미만** |
| **OpenAI** | GPT-4o | $5.00 | $15.00 | **$3.00** |
| **Google** | Gemini 1.5 Flash | $0.075 | $0.30 | **$0.05 미만** |
| **Google** | Gemini 1.5 Pro | $3.50 | $10.50 | **$2.00** |
| **Anthropic** | Claude 3.5 Haiku | $0.25 | $1.25 | **$0.15 미만** |

> **결론**: 가장 작고 빠른 모델(GPT-4o-mini, Gemini Flash 등)을 사용할 경우 한 달 내내 매일 10개 종목을 분석시켜도 **커피 한 모금 값(100원 이하)** 수준으로 매우 저렴하다. 가장 성능이 뛰어난 대형 모델(GPT-4o, Gemini 1.5 Pro)을 사용하더라도 월 5천원 이내로 커버 가능하다.

### 완전 무료(Free Tier) 사용 가능 여부
개인 토이 프로젝트 및 소규모 자산 운용 수준에서는 **비용을 0원(무료)으로 진행하는 것이 충분히 가능하다.**

1. **Google Gemini API (추천)**
   - **무료 정책**: 분당 15회 요청(RPM), 일일 1,500회 요청, 하루 100만 토큰까지 완전 무료 제공.
   - **적합성**: 하루 10종목 분석 시 분당 15회 제한에 걸리지 않도록 종목 분석 사이에 `Task.Delay(5000)` 등 5초 대기를 주면 완전 무료로 강력한 **Gemini 1.5 Pro/Flash** 모델을 사용할 수 있다.

2. **Groq API (Llama 3 모델)**
   - 오픈소스 모델의 초고속 추론을 제공하는 Groq은 개발자에게 넉넉한 무료 한도를 제공한다. 속도가 매우 빨라 퀀트 결합에 유리하다.

3. **OpenAI / Anthropic**
   - 아쉽게도 현재 OpenAI와 Anthropic의 공식 API는 크레딧을 선결제해야만 하는 완전 유료 모델이므로 무료 사용은 불가능하다.

### 아키텍처 연동 시 추가 필요 사항 (체크리스트)
현재 Mock 환경을 실제 API 연동 환경으로 전환하기 위해서는 다음 작업들이 추가로 필요하다.

- [ ] **HttpClient 통합**: `KisBrokerClient`에 사용된 `Polly` 재시도 로직을 동일하게 적용한 AI 전용 `HttpClient` 모듈 구현 (AI API도 타임아웃, 429 에러 발생 빈도가 높음)
- [ ] **프롬프트 엔지니어링**: OHLCV 배열 데이터를 모델이 이해하기 쉬운 텍스트 (또는 CSV 형태)로 변환하는 `PromptBuilder` 클래스 구현
- [ ] **JSON 파싱 안정성 (Structured Outputs)**: 모델이 가끔 JSON 형식을 어기거나 불필요한 설명(마크다운 코드 블록 등)을 포함할 수 있으므로, 응답을 안전하게 Deserialize 할 수 있는 전처리 필터 로직 구현 (또는 OpenAI의 Structured Outputs 기능 활용)
- [ ] **Rate Limit 회피 대기 로직**: 여러 종목이 1분 이내에 동시에 분석될 때 AI API 서버의 Rate Limit에 걸리지 않도록 큐(Queue) 기반 또는 순차 `await Task.Delay` 로직 반영
- [ ] **보안 처리**: AI 모델에는 `TB_MARKET_SNAPSHOT`의 시세 및 지표 데이터와 `Ticker` 정보만 전송하며, `AccountNo`, `API Key`, `현재 잔고 및 수익금액` 등 개인의 계좌 자산 정보는 절대로 프롬프트에 포함되지 않도록 마스킹 처리 필수.

## 정리 / 결론
현재 구현된 `CombineSignals()` 아키텍처는 훌륭한 방어기제다. (AI가 오작동하여 무조건 BUY를 외치더라도 퀀트 조건이 부합하지 않으면 HOLD 되도록 설계).
다음 단계로 나아갈 때는 **Google Gemini API의 무료 티어**를 활용하거나 **GPT-4o-mini**를 활용하여 월 1,000원 미만의 초저비용으로 운영하는 방식을 추천한다.
