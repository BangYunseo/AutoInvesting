# 문서 동기화 — 리딩 가이드/코드맵 최신화 및 orphan DTO 정리

## 개요
> 문서 드리프트를 해소하기 위해 코드 리딩 가이드와 코드맵을 실제 아키텍처(고정 수량 템플릿 + 월배정)에 맞게 최신화하고, 참조 0건인 orphan DTO 4개를 제거한 작업 기록이다.

## 배경 / 목적
사용자 요청: 현재 프로젝트가 어떤 설계 패턴으로 만들어졌는지(주먹구구인지 아닌지), 그리고 "사람이 코드를 읽는 흐름"을 안내하는 문서가 적절한지 점검.

점검 결과 **아키텍처는 계층형(Controllers→Core→Data, Utils 횡단) + DI + 인터페이스 추상화 + 순수함수 분리로 잘 설계됨** (MVP/MVVM은 이 Headless REST 백엔드에 적용 대상 아님). 진짜 문제는 코드가 아니라 **문서 드리프트**여서 아래를 정리함.

## 본문
### 진행 내역
1. **CODE_READING_GUIDE.md 최신화**: 이전 "목표비중 비례 매수 + 잔돈(leftover) 이월 / DCA_TARGETS" 모델을 설명하고 있었으나, 실제는 "고정 수량 템플릿 + 월배정 / DCA_TEMPLATES·DCA_MONTH_MAP". Step 2·3·4·6 재작성, 순수함수 2개(SelectTemplate/PlanPurchases) 강조, Auth/Price 컨트롤러 반영.
2. **CODE_MAP.md 재생성 복구**: 문서가 삭제된 Phase 4~5 파일(SmartOrderEngine, Gemini*, Quant/*, Monitoring 등)을 나열하고 "70개 파일"로 낡아 있었고, 재생성 스크립트도 부재했음. → `regen-codemap.ps1`을 git에서 복구 후 실행 → 실제 39개 파일 기준으로 재생성.
3. **orphan DTO 4개 삭제**: 참조 0건 확인 후 제거 (AdaptiveThresholdStatusDto/DailyTokenUsageDto/StrategySummaryDto/AssetMasterDto — 제거된 판단 레이어 잔재).
4. `dotnet build` 오류 0 확인.

### 인계 메모
- **동시 세션 작업 중**: "절세 보조기능 + 시장 국면 브리핑" 기능이 미커밋 상태로 진행 중 (TaxEstimator, MacroBriefingService, MacroController, FredClient, Macro*Dto, SellTaxEstimateDto, 관련 Tests, OrderController.PreviewSell, Order.jsx, appsettings.json). 본 작업은 이 파일들과 겹치지 않음.
- 재생성된 CODE_MAP.md에는 위 WIP 파일도 정확히 포함됨.

## 정리 / 결론
- 사용자 검토 후 커밋(문서 3건 + DTO 삭제 4건 + 스크립트). 동시 세션 WIP와 별개 커밋으로 분리 권장.
- 구조 변경 시 `pwsh Documents/regen-codemap.ps1` 재실행 습관화(CODE_MAP은 자동 생성물, 수동 편집 금지).
