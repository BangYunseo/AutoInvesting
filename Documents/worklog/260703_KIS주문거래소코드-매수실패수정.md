# 260703 KIS 주문 거래소 코드(OVRS_EXCG_CD) 하드코딩으로 인한 매수 전량 실패 수정

- 상태: 진행중
- 작성/갱신: 260703

## 목적 / 요청
새벽 DCA 적립 사이클에서 메일이 오지 않아 원인을 추적한 결과, 두 가지 별개 문제가 확인됨.
그중 **매수 자체가 계속 실패(0주 체결)** 하던 근본 버그를 수정한다.

- 증상: 7/3 01:24 사이클에서 GLD·SCHD 주문이 모두 `주문 에러: 해당종목정보가 없습니다`로 거부 → 0주 체결.
  (`TB_TRADE_HISTORY` 전체 건수 0 — DCA 전환 이후 한 주도 체결된 적 없음.)
- 근본 원인: 현재가 조회 API(EXCD)와 주문 API(OVRS_EXCG_CD)의 **거래소 코드 체계가 다른데**,
  주문(`PlaceOrderAsync`)이 `OVRS_EXCG_CD = "NAS"` 로 **하드코딩**되어 있음.
  - 현재가 조회는 `NAS/NYS/AMS`를 순회해 종목이 있는 거래소를 찾음(GLD/SCHD는 AMS=NYSE Arca에서 조회됨) → 가격·계획·금액은 정상.
  - 주문은 항상 `"NAS"` 로만 나가서, NAS(나스닥)에 없는 종목(NYSE/NYSE Arca 상장)은 전량 거부됨.
  - 게다가 `"NAS"`는 주문 API가 기대하는 값(`NASD/NYSE/AMEX`) 규격에도 어긋남.

> 참고: 이메일 미발송은 별개 문제(원인=Render 환경변수 `ADMIN_EMAIL` 미설정). 이 건은 사용자가 Render 콘솔에서 처리. 본 보고서 범위 아님.
