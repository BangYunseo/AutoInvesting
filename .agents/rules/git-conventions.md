# Git 커밋 컨벤션

## 커밋 타입
| 타입 | 설명 |
|------|------|
| feat | 새로운 기능 추가 |
| fix | 버그 수정 |
| docs | 문서 수정 |
| style | 코드 스타일 변경 (코드 포매팅, 세미콜론 누락 등) |
| design | 사용자 UI 디자인 변경 |
| test | 테스트 코드, 리팩토링 |
| refactor | 리팩토링 |
| build | 빌드 파일 수정 |
| ci | CI 설정 파일 수정 |
| perf | 성능 개선 |
| chore | 자잘한 수정이나 빌드 업데이트 |
| rename | 파일 혹은 폴더명을 수정만 한 경우 |
| remove | 파일을 삭제만 한 경우 |

## 규칙
- 컨벤션 타입 뒤에 괄호로 추가 설명을 덧붙이지 않음
  - ✅ `feat: KIS API 토큰 매니저 구현`
  - ❌ `feat(core): KIS API 토큰 매니저 구현`
- 한 번에 모든 변경을 커밋하지 않고, 기능 단위별로 끊어서 커밋
- 커밋 메시지는 한국어로 작성
- 제목은 50자 이내
